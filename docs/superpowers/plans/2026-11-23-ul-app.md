# Unlaw App (menu bar, hotkeys, palette) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An always-running Unlaw.app (menu bar items, global hotkeys, a command palette, glass panels) that runs every `ul` command, plus the install linkage and agent skills.

**Architecture:** New workspace crate `app/` (package `unlaw-app`, binary `ul-app`): pure, tested modules (`spec`, `args`, `template`, `settings`) and a thin GUI shell on tao/wry/tray-icon/global-hotkey that only ever runs `$UL <cmd> <args>`. Commands describe themselves in `commands/<name>/app.toml`; shipped commands' descriptions are embedded in the app. The core gets `ul gui` (install bundle, LaunchAgent, start/stop/status/config) and the `gui` feature.

**Tech Stack:** Rust 2021, tao 0.37, wry 0.57, tray-icon 0.26, global-hotkey 0.10, toml_edit 0.22, serde_json 1; HTML/CSS/JS (vanilla) embedded with include_str!.

**Spec:** `docs/superpowers/specs/2026-11-23-ul-app-design.md` (read the Revision section first).

## Global Constraints

- No Swift. macOS-only code lives in `app/src/platform/macos.rs` behind `#[cfg(target_os = "macos")]`.
- GUI crates are deps of `unlaw-app` only; `ul`/`ule` dependency lists stay unchanged.
- `unlaw-app` version = root `Cargo.toml` version (test).
- Default palette hotkey `ctrl+space`.
- Command values reach argv only through placeholders, one argv element each, never a shell.
- Everything from commands/config is put into pages with textContent; IPC is a whitelist.
- A command is never run to describe it; status/actions run with stdin null, `UNLAW_APP=1`, own process group, timeouts (status 10 s, action 120 s).
- Tests never touch real windows, hotkeys, launchd, /Applications or the network.
- Core Rust/Python files are patched via Bash scripts (format hook), new files may use Write.

## Review Focus

1. A broken `app.toml` (sidecar or settings) → readable error in the menu/palette, everything else keeps working (spec/settings tests).
2. A command that hangs or prints megabytes → killed at its timeout, output capped at 64 KB (runner test).
3. Placeholder values containing spaces, `--flags`, quotes, empty strings → exact argv (args tests).
4. A hotkey string that cannot be parsed or registered → warning, other hotkeys still work (settings parse test).
5. Two `ul gui install` runs / an existing non-Unlaw `Unlaw.app` → idempotent, never deletes a bundle without our marker (gui tests).

### Task 2: `unlaw-app` crate, pure modules

**Files:** Create `app/Cargo.toml`, `app/src/lib.rs`, `app/src/spec.rs`, `app/src/args.rs`, `app/src/template.rs`, `app/src/settings.rs`, `app/src/runner.rs`, `app/defaults/*.toml`; Modify root `Cargo.toml` (`members = ["ule", "app"]`).

**Interfaces (produced):**
- `spec::Spec { title, icon, terminal: bool, status: Option<Status>, actions: Vec<Action>, panel: Option<Panel>, open: Option<Open> }`, `Status { args, every: u64 (>=2), text: Option<String>, when: Option<String>, otherwise: Option<String> }`, `Action { id, label, args }`, `Panel { fields: Vec<Field>, submit: Vec<Action> }`, `Field { id, kind: FieldKind (Choice|Toggle|Text|Number|Duration|Time|Date), label, options: Vec<String>, default: Option<toml Value as String/bool> }`, `Open { args }`.
- `spec::parse(text: &str) -> Result<Spec, String>` (unknown keys refused, caps: 32 actions, 24 fields, 64 options, 64 args, strings ≤ 200 chars, no control chars).
- `spec::for_command(name, dir: Option<&Path>, summary) -> Result<Spec, String>`: sidecar > embedded default > generic (`Run`).
- `args::expand(template: &[String], values: &BTreeMap<String, Value>) -> Result<Vec<String>, String>`: `{id}`, `{id?A}`, `{id?A:B}`, literal text otherwise; an element that expands to empty is dropped; unknown id = error.
- `template::render(text: &str, json: &serde_json::Value) -> String` with filters `clock` (seconds → `h:mm`/`m:ss`), `int`, `pct`, `gb`; `template::status_text(status, stdout) -> StatusText { text, state }`.
- `settings::Settings { palette: Option<Hotkey>, hotkeys: Vec<Binding>, menubar: Vec<String>, theme }`, `settings::parse(text) -> (Settings, Vec<String> warnings)`, `settings::pin(text, name) / unpin` (toml_edit, comments kept), `settings::DEFAULT` text with `palette = "ctrl+space"`.
- `runner::run(ul: &Path, argv: &[String], timeout: Duration) -> Outcome { code: Option<i32>, stdout, stderr, timed_out }` (own process group, 64 KB cap each, kill group on timeout).

- [ ] Write unit tests for each module (cases from Review Focus 1-4 and: awake status `{"active":true,"remaining_seconds":5040}` → `1:24`; inactive → `off`; sys `{"cpu":{"usage_percent":14.6}}` with `CPU {cpu.usage_percent|int}%` → `CPU 15%`).
- [ ] Implement; defaults for every shipped command per spec table (awake panel + status, sys status, desk open, timer panel, clip, weather, music/gpt/claude/obsidian/lofi/netflix/steam/minecraft/zed/work open action, yt panel, capture actions, git/tg/agent/py/rust/cpp/mac/game/lm terminal, zip/app/browser).
- [ ] Test `every_default_parses` and `version_matches_root`.
- [ ] `cargo test -p unlaw-app` pass, `cargo clippy -p unlaw-app --all-targets` clean. Commit.
