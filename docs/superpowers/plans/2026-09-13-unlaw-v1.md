# Unlaw V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a small, stable, extensible macOS CLI whose commands are discovered from `main.py` files.

**Architecture:** `unlawful.cli` handles system commands and delegates all functional commands to independent scripts. User commands override packaged built-ins and are executed in subprocesses so arguments and exit codes behave like ordinary CLIs.

**Tech Stack:** Python 3.11+, standard library, unittest, hatchling.

**Spec:** `docs/superpowers/specs/2026-09-13-unlaw-v1-design.md`

## Global Constraints

- Keep the runtime dependency-free and macOS-focused.
- Never write outside `${XDG_CONFIG_HOME:-~/.config}/unlaw` except when a user explicitly requests a project in the current directory.
- Do not require macOS Harness for non-`mac` commands.
- Do not add AI, voice input, GUI, server, cloud, or integration frameworks in V1.
