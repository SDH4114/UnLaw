# Unlaw 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Unlaw V1 into a polished configurable daily CLI while preserving directory-based commands.

**Architecture:** A standard-library configuration module owns idempotent layout creation, TOML loading, validation, and atomic writes. The CLI expands aliases and routes system commands; the runner remains the only functional-command execution boundary, while independent built-ins read the shared config as needed.

**Tech Stack:** Python 3.11+, `tomllib`, `unittest`, hatchling build backend.

**Spec:** `docs/superpowers/specs/2026-09-13-unlaw-1.0-design.md`

## Global Constraints

- Keep `commands/<name>/main.py` as the sole extension contract.
- Use no runtime dependencies and never use `shell=True`.
- Preserve user files; reset is explicit and backed up.
- AI, voice input, GUI, daemons, cloud services, and a plugin registry remain out of scope.
