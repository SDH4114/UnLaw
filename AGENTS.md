# Unlaw project notes

- License: MIT (`LICENSE`, `Cargo.toml`, `pyproject.toml`).
- Update: `ul update [--check] [--force] [--branch|--tag]` reinstalls `unlaw` and `ule` from GitHub with `cargo install --locked --force --git` into the running binary's prefix; it skips when the remote commit (`git ls-remote`) equals the build's commit, the build's cargo features match `core.features` and ule is installed, and sets `CARGO_TARGET_DIR=~/Library/Caches/unlaw/cargo-target` (unless already set) so both packages share dependency builds (keep crossterm/toml_edit features identical in both Cargo.toml files). It never touches user config, data or edited commands.
- Reinstall/remove (`rust/src/remove.rs`, raw system commands): both print what they do and need `y` on stdin (or `--yes`). `ul reinstall` deletes `~/Library/Caches/unlaw/cargo-target` (only when CARGO_TARGET_DIR is unset), installs main like `ul update --force`, and only after a successful build moves config.toml/ule.toml into `<config>/backups/reinstall-<time>/`, writes defaults keeping `core.features` and `storage.root`, takes default seeds out (`layout::reset_seeds`: untouched deleted, edited moved to the backup, symlinks kept) and runs the new `ul init`. `ul remove` boots out and deletes the `com.unlaw.agent`, `com.unlaw.awake` and `com.unlaw.clip` launchd jobs (one table, `COMMAND_JOBS` in remove.rs: `ul remove <cmd>` and `ul features remove` drop the job of each removed command too), removes skills, the ~/.zshrc shell block (not the PATH line), the Keychain token, the whole config dir, `~/Library/Caches/unlaw` and the binaries (`cargo uninstall`, then files); a storage.root outside the config dir and the HF cache are kept. `ul remove <name>` deletes `commands/<name>` (a symlink only as a link) and drops a default command from `core.features` so it is not reseeded; system, core and built-in (`lm`, `game`) names are refused. Tests (`tests/test_remove.py`) fake cargo, launchctl and security on a restricted PATH.
- Purpose: small macOS CLI that dispatches commands from `commands/<name>/` (entry point `main.py`, `main.sh`, `main.js` or executable `main`, checked in that order).
- Core: Rust crate (`Cargo.toml`, `rust/src`), binaries `ul` and `unlaw` (plus `ula`/`unlawagent` = `ul agent ...`, `run_agent` in `lib.rs`); deps limited to `toml_edit`, `sha2`, `libc`, `crossterm` (games, `ul features choose`), `serde_json` (`ul lm` API); the objc2 crates (`objc2`, `objc2-foundation`, `objc2-core-foundation`, `objc2-core-media`, `objc2-av-foundation`, `objc2-screen-capture-kit`, `block2`) are optional and only linked into `ul-rec` (feature `capture`). Dispatcher, config, system commands, completion, doctor, shell integration and project templates live there. Current release is 4.0.0 (`ul --version` adds the build commit); `Cargo.toml` and `src/unlawful/__init__.py` versions must match (build.rs enforces it).
- Commands: Python 3.11+, standard library only. `src/unlawful` holds seeded command sources, their help (`command_help.py`), legacy hashes and `DEFAULT_CONFIG`; `rust/build.rs` runs `rust/gen_assets.py` to embed them, so build needs Python 3.11+. System command help lives in `rust/src/help.rs`.
- Command contract: commands receive `UNLAW_COMMAND`, `UNLAW_COMMAND_DIR`, `UNLAW_CONFIG_DIR`, `UNLAW_STORAGE`, `UNLAW_BIN` (absolute path of the running ul); `main.py` runs with `UNLAW_PYTHON`, else `core.python`, else the newest `python3.x` on PATH (python3.20 down to 3.11, a range so new Pythons need no release; build.rs and install.sh search the same way); when none is on PATH, `installed_python` looks in ~/.local/bin, /opt/homebrew/bin, /usr/local/bin, the python.org framework and ~/.pyenv/shims before plain `python3`, because an app opened from the Dock gets PATH=/usr/bin:/bin:/usr/sbin:/sbin and /usr/bin/python3 (3.9) has no tomllib (every seed then failed with ModuleNotFoundError). Descriptions for `ul commands --describe`/completion come from `help.txt`, the `main.py` docstring or a script's first comment, never by running the command. A lone `--help`/`-h` of a seed whose `main.py` is byte-identical to the shipped seed prints `SEED_HELP` from ul without starting Python (`layout::untouched_seed_help`; not with --dry-run/--verbose/core.verbose/core.show_timing); this relies on every seed printing its static `COMMAND_HELP` for that, so a seed's help must never depend on config or environment. Changing a seed's content requires adding the previous release's hashes to `LEGACY_SOURCE_HASHES` (and the hash of any dev build installed on Haos's Mac). A copy that differs from an official source only in blank lines or the summary docstring also counts as untouched: `normalized_source` (Python `command_sources.py`, Rust `layout.rs`, kept identical) is compared with the current seed and with `LEGACY_NORMALIZED_HASHES`, generated from every commit's seeds; regenerate it when releasing. Tests that call unlawful code in-process must patch HOME/XDG_CONFIG_HOME/PATH first, or `load_config()` seeds the real `~/.config/unlaw`; `tests/ulbin.py` puts a failing fake `security` first on PATH.
- Installer (`install.sh`): needs the Command Line Tools (`xcode-select -p`, checked before rustup/cargo), then after `cargo install` runs `ul doctor --fix` (PATH line + shell integration in ~/.zshrc) and tells the user to open a new terminal when `$root/bin` is not before `/usr/bin` in its PATH: macOS ships `/usr/bin/ul` (underline filter waiting on stdin), so without that line `ul` looks hung and `ul <cmd>` says "No such file or directory". Tests: `InstallerShellTests` in `tests/test_features.py` (fake cargo installs the test binary).
- User data: `${XDG_CONFIG_HOME:-~/.config}/unlaw`; a source build and first non-help CLI invocation bootstrap it without overwriting user files.
- Extension rule: only system commands live in the dispatcher; every other command is seeded as standalone source into `${XDG_CONFIG_HOME:-~/.config}/unlaw/commands/<name>/main.py`. Legacy official import wrappers are migrated, but manually edited command files are never overwritten.
- Seeded sources contain only that command's logic and minimal config helpers/defaults; unrelated command code must never be concatenated into them.
- Configuration: `config.toml` is validated and atomically written with `toml_edit`, preserving comments and unknown keys; validation rules exist in both `rust/src/config.rs` and `src/unlawful/config.py` and must stay identical; aliases are token arrays, not shell strings.
- Test: `cargo test --workspace`, `cargo clippy --workspace --all-targets`, and `python -m unittest discover -s tests -v` (black-box tests build and run `target/debug/ul`; tests must never reach the network or real user tools — use fake executables on a restricted PATH and local servers).
- Build check: `cargo build --release --workspace`; install with `cargo install --path . --root ~/.local --force` and `cargo install --path ule --root ~/.local --force` (install.sh and `ul update` install both packages from GitHub with two `cargo install --git …` calls: unlaw with the chosen features, then ule).
- Project templates live in `templates/{commands,python,rust,cpp}` and may override generated files.
- Templates (working environments, `ul template save|edit|show|rm|list`, `ul <name> [--focus|--no-focus] [--dry-run]`): model and TOML in `rust/src/workspace.rs` (version 2: `path`, `focus`, `[[window]]` app/open/frame/screen/urls, `[[window.tab]] panes = [{dir, run, split}]`, strict unknown-key checks; the original `path`/`app`/`ai` files still load as `legacy` and launch exactly as before: `open -a <apps.editor|Obsidian> path`, then ChatGPT), commands and launching in `rust/src/template_cmd.rs`, the macOS side in `rust/src/desktop.js` (embedded, `osascript -l JavaScript -e <script>`, one JSON request on stdin so links/commands never reach argv; modes `snapshot` and `apply`). Launch: plan validates every folder first, apps open with `open -a` from Rust (testable), then one osascript run places frames (System Events, needs Accessibility), creates Ghostty windows/tabs/splits through Ghostty's AppleScript (`run` = `initial input` + newline so the pane stays a shell), opens browser windows (Safari/Chromium scripted; others via NSWorkspace) and hides other apps for focus. osascript is skipped when no window needs it. Ghostty/browser window ids go to `storage.root/runtime/templates.json` as `{id, pid, spec}`; a second run reuses a window only when the app pid is the same (browser ids restart after a relaunch) and `spec` (hash of kind/app/tabs/urls) still matches, so an edited template opens a new window; `rm` drops the entry. Placement only ever moves the window it opened or the one matching `open` (title contains its name or AXDocument equals it), never another window of the same app; a window the script does not answer for is a failure. One failing window never stops the others (exit 1). Frames are fractions of the display's visible frame (top-left global coordinates, screen 1 = main); `relative_frame` converts snapshots. Non-TTY `save` uses numbered prompts (tests), a TTY gets `checklist.rs`. The shell function cds only when every extra argument is `--focus`/`--no-focus` (any other, `--dry-run` included, keeps the cwd), and runs `ul _template-path` only when `${XDG_CONFIG_HOME:-$HOME/.config}/unlaw/templates/projects/<name>.toml` exists (or the base starts with `~`), so ordinary commands start ul once. Tests: `tests/test_templates.py` (fake osascript logging stdin); `tests/ulbin.py` puts a failing fake `osascript` first on PATH so no test reads or moves real windows. Security (from the audit, keep it): every string in a template is refused when it contains control characters, everything printed (`describe`, `list`, the save checklist) goes through `printable`, snapshot strings with control characters are dropped, `is_url` needs a letter first so `open` never gets an option, and `_template-path` exits 3 for a template named like a system/built-in/installed command or alias, so it never shadows `ul git`. `place` sets the size before the position: macOS will not narrow a window touching a display's right edge (measured with Ghostty).
- macOS Harness is optional; only `ul mac` and its doctor checks may depend on it.
- Git: `ul git` (seed = `src/unlawful/git_hosts.py` + `built_in_commands/git/main.py`; helpers are `_hosts_*` / `_git_*` so the concatenated seed has no name clashes). `ul git [msg]`, `push [msg]`, `commit`, `sync` all run add → secrets guard → commit (prompt when no message) → push; the guard unstages staged additions/changes (not deletions) named .env/.env.* (not .env.example), *.pem, *.key, *.p12, private id_rsa*/id_ed25519*, or > 50 MB and exits 1 unless `--allow-secrets`. Push = origin (a branch without upstream gets `-u origin <branch>`), then every `mirror-*` remote (`git push <mirror> HEAD`; a failing mirror only warns). `init` (refuses inside a work tree; `-b main`; merges a per-type .gitignore, never removing lines; first commit; `--connect`), `connect SPEC` (host name github/gitlab/codeberg/gitea → `create_repo`, private unless `--public`; otherwise `expand_remote`: `gh:`/`gl:`/`cb:` short forms, URLs, local paths; refuses to replace a different origin without `--force`; rerunning with the host origin already points to reuses it; SSH gate via `ssh_check`, offers `ensure_ssh_key` + key page; `ls-remote` check; push -u), `mirror add|list|remove`, `token HOST [--url]` (`prompt_token`: `security add-generic-password ... -U -w` with `-w` last, so security prompts and the token never enters argv; Keychain service `unlaw.git.<API server hostname>`, account unlaw, so a token is only ever sent to the server it was saved for; GitHub uses `gh auth login`; a token passed in (`save_token`) goes to `security -i` on stdin, then is read back, because `security -i` exits 0 even when a command failed), `open`, `pr` (pushes, then `gh pr create --fill` on GitHub when gh exists, else the host's compare/MR page), `undo [--list|COMMIT]` (soft reset to HEAD~1 or to COMMIT by hash/message part, refused when any undone commit is on a remote branch; `status`/`pull` were removed and refused with exit 2 so they never become commit messages). GitHub creation goes through `gh` with an explicit owner (`gh api user`); GitLab/Gitea/Codeberg through their APIs with the Keychain token, redirects never followed, the token scrubbed from every error, answers capped at 1 MB, server text stripped of control characters. Hardening from the security audit (keep it): API repo URLs go through `_git_checked_remote` and `ls-remote --end-of-options`; the guard unstages with `--literal-pathspecs reset --pathspec-from-file=-` and compares names casefolded; init refuses a symlinked .gitignore (O_NOFOLLOW); ssh_check uses `StrictHostKeyChecking=yes` (never accept-new). Tests: `tests/test_git_command.py` (real git, local bare remotes, stubbed hosts via `tests/fake_git_hosts.py`), `tests/test_git_hosts.py` (fake gh/security/ssh on PATH, local HTTP API). Since 3.19.3 (keep it): the guard's reset runs with `-C <root>` (names are root-relative); `sync` pulls with `--rebase --autostash`; message words starting with `-` are refused as unknown options (exit 2) except after `--`, so a typo like `ul git --amend` is never committed and pushed; printed remote URLs mask `user:token@` (`_git_shown`).
- Desk: `ul desk` (seed: `src/unlawful/kanban.py` + `reminders.py` + `canvas.py` + `desk_ui.py` + `desk.py`). Terminal access for people and agents (no server): `list [--json]`, `show [board] [--json] [--reminders]` (the default board is `todo.vault_path` + `todo.file`; the `[todo]` config section stays for that), `add <text> [--column C]` (first column by default, `quick_text` dates), `move <n> <column>`, `done <n>` (to `todo.completed_column` or a Done-like column); add/move/done take `-b <board>`; card numbers count across all columns like `KanbanBoard.numbered_tasks`. The agent's `today`/`todo_list` read `ul desk show --json`, `todo_add`/`todo_done` run `ul desk add/done`. `ul todo` was removed in 3.17.0: `todo` is in `RETIRED_COMMANDS` (untouched seeds deleted on startup, edited kept) and in `features.RETIRED` (still valid in `core.features`, ignored; `FEATURE_RETIRED` in Rust). `ul desk --help` is kept short (under 30 lines, a test checks it); page details live in README. The page server serves the same board on 127.0.0.1 with stdlib `http.server`: Host check, random token (page `?token=`, API `X-Desk-Token`), CSP, no CORS. The file is the source of truth: every change carries the board version (sha256 of the bytes, also the ETag) and is refused with 409 + the fresh board when the file changed; the page polls every 2 s and retries a conflicting change once by card line and column name. The page (`desk_ui.py`, vanilla JS) builds nodes with textContent only, never innerHTML, because card text is user data. Look (3.19.1): amber/yellow on white or warm black; colors only through the CSS tokens in both themes (`--accent` is a fill with `--on-accent` text, `--accent-ink` is for text and lines on the page background, `--energy` orange marks focus/today); the board picker is a flat menu (`#boards`, `loadBoards`), not a `<select>`, because a macOS select opens around the chosen item and hid the boards above it. The logo is `assets/logo.svg` (white rounded square, amber `UL` drawn as strokes, no font; `assets/logo-dark.svg` is the same on #0b0b0a); desk_ui.py inlines both files as header marks (CSS shows the one for the theme) and as the favicon's `data-light`/`data-dark` (`applyTheme` swaps the href, because the page theme can differ from the system one). `DeskLogoTests` fails when the page and the files differ, so change a file and re-inline it. Pomodoro state is `storage.root/desk/pomodoro.json` under a flock (`.lock`), shared by the server's ticker thread (notifications via `osascript`) and `ul desk pomodoro`; finished focus sessions go to `pomodoro.jsonl`, recent boards to `recent.json`. Reminders layer (`reminders.py`, `desk.reminders`, default on; `ul desk --reminders`, board id `reminders:`): every Apple Reminders list is a column, every open reminder a card; it is a separate layer that never touches the .md boards (`Desk.layer`; `Desk.path` keeps the last file board). It goes through EventKit in a JXA script (`osascript -l JavaScript`, one JSON request per run, ~0.2 s); the first run waits up to 90 s for the macOS access dialog, polling the status (the completion block may never fire) and making a new EKEventStore after the answer, and the Python timeout (120 s) stays above the script's waits so the user gets its message, not a kill); the Reminders app's Apple Events were measured at 12-22 s on a list with ~900 finished reminders, so never use them. Writes are two-way: add/edit (`@{date}` = due date, an existing time of day kept), move to another column = move to that list, done completes, delete removes, new column = new list; order inside a list is not settable, so same-column moves are no-ops; version = hash of the normalized snapshot, re-read fresh before every write. Boards folder: `desk.boards_dir` (default `boards`, relative to the config dir); a bare name (no `/`, no `.md`, not starting with `.`/`~`) means `<boards_dir>/<name>.md` in `ul desk`, `new`, `path`, `stats` and the page's "New board…" (folder created on demand); paths and `*.md` names keep their old meaning. The page's "New board…"/"Open another board…" go through `POST /api/boards/choose` `{create}` (`board_choose`: `choose file name` save dialog / `choose file` open dialog via osascript, start folder = boards_dir or HOME, `.md` appended to a new name; same `{path|null}`/`{unavailable}` answers and `choose_lock` as `/api/canvas/choose`); a picked existing file is opened, never overwritten (`board_file` creates with `x`). Columns move by dragging their heading: op `move_column` `{column, name, to_index}` (name must match, else Conflict; the whole `##` section moves with its cards); refused on the Reminders layer, whose list order EventKit cannot set. Deleting a board (`ul desk rm <board>`, page "Delete this board…" → `POST /api/boards/delete` `{path}`, `trash_board`/`Desk.delete_board`) moves it to `~/.Trash` (free name `X 2.md`, never overwrites; a symlinked board loses only the link), refuses the default board (`todo.vault_path` + `todo.file`, read by `ul desk show/add/done` and the agent) and, before anything moves, the last board when Reminders cannot take its place; an open board is replaced by the next recent/folder/default board. Paths are compared resolved (`/var` vs `/private/var`). Tests: `tests/test_desk_reminders.py` (FakeReminders subclass overriding `call`, fake `osascript` for the seed). Games tab: `Arcade` in desk.py runs at most one `$UNLAW_BIN game --stream` (validated game/level/size, own process group) and relays its NDJSON frames over `POST /api/game/stream` (fetch streaming, so the token stays in the header; one reader per session; blank keep-alive lines every 2 s detect a closed page, which kills the game); input is batched through `/api/game/input` and re-serialized from a whitelist; `/api/games` reads `arcade.toml` for the records. The page draws the cell grid on a canvas (box/block characters as shapes, edges pixel-snapped) and never reimplements a game. Studio tab (`studio_ui.py`): the Record tab is OBS-style (preview with 8 handles drawn in an overlay `#stageUi` outside the clipped stage, inspector on the right with X/Y/W/H in pixels of a 1080p frame, docks Scenes / Sources (top = front) / Audio mixer / Controls, right-click menus, Delete, arrows, ⌘Z undo of setup/project snapshots; lock is page-only in localStorage); panels are movable and resizable (`layoutFrame`: the preview plus five slots for inspector, Scenes, Sources, Audio mixer and Controls; gutters `gut-right`/`gut-bottom`/`gut-col` set the CSS variables `--right`, `--bottom`, `--c1..3`; dragging a panel's `header` onto another slot swaps them; `parseLayout` validates localStorage `studio-layout` and falls back per value; the header's layout button resets it); "Record audio only" (and key A) posts `{mode: "audio"}` = `ul capture record audio`, the microphone alone as its own project; while one runs, `#voiceWave` (a canvas over the preview) draws a Voice Memos style wave from the page's own microphone (`addWaveSample`: loudest level per 0.08 s slice of recording time, `wavePeaks` one pass for the overview strip; a microphone opened only for the wave is closed after, `releaseWaveMic`); `toggleRecord` sets `recordBusy` before any await and also waits for a setup save already on its way, so a double press sends one request; a failed `/api/studio` or setup load is shown with Try again (it used to re-request in a loop); icons are SVG strokes, never emoji; `studioKeydown` runs before the page-wide keys (they swallow Esc and ⌘); mixer on/off = `audio.<input>.enabled` (off closes the page's microphone; `muted` stays the export flag); the screen preview is live through `getDisplayMedia` once clicked, else a snapshot every 2 s (each `ul capture preview` costs ~0.9 s). Studio tab: `Studio` in desk.py only calls `$UNLAW_BIN capture ... --json` (validated arguments; stop runs in a thread and reports through `/api/studio/status` `saving_done`), so terminal and page share one recording and library; `/media/{file,thumb,preview}` take the token as `?t=` (media elements cannot send headers), serve byte ranges (video seeking) and only files directly inside `captures/{screenshots,recordings}`. Canvas tab: `canvas.py` (stdlib, seeded with desk) reads/writes JSON Canvas `.canvas` files (Obsidian-compatible: nodes text/file/link/group, edges) and keeps every unknown key as read; Excalidraw-style drawings are the extra top-level `unlaw` = `{version: 1, elements: [...]}`, validated with caps (20000 elements/nodes/edges, 200000 points, 20000 text chars; bad input = ValueError = HTTP 400). Files are written tab-indented and atomically (mode kept); the version is `version_of(bytes)` like boards. Desk API: `GET /api/canvases` (canvas dir + recent `storage.root/desk/recent-canvas.json`, max 8), `GET /api/canvas[?path=]` (sets current, 404 `missing`), `POST /api/canvas` (whole document, 409 with the fresh canvas when the version differs; the only endpoint with a 16 MiB body limit), `POST /api/canvases` `{path, create}` (bare name = `<desk.canvas_dir>/<name>.canvas`, default `canvas` in the config dir; create never overwrites). `POST /api/canvas/new` creates the first free `canvas-N` (exclusive create), `/api/canvas/rename` `{path, name}` renames inside the same folder (hard link + unlink, never overwrites; version unchanged), `/api/canvas/choose` runs the macOS open dialog through `osascript` (`CHOOSE_CANVAS_SCRIPT`, folder in argv; `{path: null}` on Cancel, `{unavailable: true}` without osascript so the page asks for a path). Page: tools stay active until the user picks another; Photoshop-style keys read by `event.code` so any keyboard layout works (V select, H hand, N card, T text, U shapes + Shift+U cycle, B brush, G fill, E eraser, `[`/`]` width, D default ink, Cmd+G group, Cmd+0 fit, Cmd+=/- zoom); toolbar buttons are inline SVG icons (`CV_ICONS`, createElementNS); any color via `<input type=color>`; stroke width is a logarithmic slider 1-100 plus a typed number field (`cvTypedWidth`), `[`/`]` or `-`/`=` step it (validator allows strokeWidth 1-100). Clicking the active eraser or shape tool opens a bubble menu (`cvToolClick`/`cvOpenMenu`): eraser mode `object` (removes what it touches) or `part` (`eraseAt`/`cutElement` split the drawn strokes, rough wobble kept via `roughStrokes`; shapes become line/freedraw pieces, a filled shape leaves its fill as a paint element; text, cards and paint are not cut; Shift+E toggles), shapes evenness 3/2/1 = roughness 0/1/2. Eraser mode, evenness and width persist in localStorage `desk-canvas-tools`. Fill tool (`cvBucket`): renders the scene without UI into an offscreen canvas (`cvSnapshot`), floods the clicked color (`floodRegion`, tolerance 40, 4-connected), grows it 1 px and traces it (`traceMask` + Douglas-Peucker) into a `paint` element (`points` outer ring + `holes`, filled even-odd, stored in world units) inserted under an empty outline or above the filled shape it was poured into; a click on a line/text recolors it, cards/groups/edges get a `color`, an area reaching the view edge falls back to `applyFill` on the shape under it or `unlaw.background` (#rrggbb, validated); Alt+click clears (removes a paint). `tg download` keeps senders' file names, never overwrites and skips files already downloaded with the same size (also numbered copies `name 2.ext`); `capture` is described in its own bullet (Capture, 3.21.0); `music`, `work`, and `yt` drive macOS apps/URLs. Default board (3.19.5): `todo.vault_path` defaults to empty and `todo.file` to `board.md`, meaning `<desk.boards_dir>/board.md`, created with `NEW_BOARD` on first use (`own_board`/`default_board` in desk.py; Rust doctor mirrors it in `system::default_board`); a config still holding the pre-3.19.5 default `~/aiwork/data-obsidian` (written into every config.toml before) uses board.md there too when that folder does not exist; a non-empty configured vault is never created. Defaults must never hold the maintainer's own paths. Board paths from the page are taken exactly (`_clean_path`, never the card-text cleaner); deleting a board given by its resolved path trashes the symlink in the boards folder that points to it, not the real file; the CLI writes through `_PlainText` (no control characters); `@+N` takes at most 5 ASCII digits.
- Canvas files and detective board (3.20.0): files dropped on a canvas or picked with the toolbar's Add go to `POST /api/canvas/upload?path=&name=` (raw body, not JSON, handled before `_body`; `MAX_UPLOAD` 256 MiB) and are copied into `<canvas folder>/attachments/` under a free name (`attachment_name` cleans the browser's name; exclusive create, `x 2.pdf`; a cut-off upload is removed); the node is a JSON Canvas `file` node with that relative path. `canvas_asset` resolves a node's file only inside the canvas's folder (symlinks out are refused). `GET /media/canvas?t=&path=&file=[&thumb=1]` serves png/jpg/gif/webp as is, anything else as a Quick Look PNG (`qlmanage -t -s 640`, cached in `<desk state>/thumbs/` by path+size+mtime, built in a temp dir and renamed); `POST /api/canvas/open-file` runs `open <abs path>`, but only `open -R` (Finder) for files `open` would run (`RUNNABLE_SUFFIXES`, or no suffix and executable), so a card in someone else's canvas never starts a program. The page never asks Quick Look for `.md` or plain-text/code files (`CV_PLAIN_FILE`: in dark mode Quick Look draws dark text on a dark page); they stay a paper sheet with an extension badge. Detective board = `unlaw.look == "cork"` in the canvas (pin button, undoable, unknown to Obsidian): cork texture (seeded tile, wrapped so it repeats without seams; `flat` in `paintScene` skips it for the fill tool's snapshot), cards tilted by an FNV hash of their id (`nodeTilt`, drawing only: hit-testing, editing and selection use the unrotated box), one push pin per card (`pinPoint`), edges are sagging red thread pin to pin drawn over the cards (`threadCurve` is a cubic, so `edgeCurveFor(map, edge, cork)` serves hit-testing and labels unchanged).
