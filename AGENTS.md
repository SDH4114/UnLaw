# Unlaw project notes

- License: GPL-3.0-or-later (`LICENSE`, `Cargo.toml`, `pyproject.toml`).
- Update: `ul update [--check] [--branch|--tag]` reinstalls from GitHub with `cargo install --locked --force --git` into the running binary's prefix; it never touches user config, data or edited commands.
- Purpose: small macOS CLI that dispatches commands from `commands/<name>/` (entry point `main.py`, `main.sh`, `main.js` or executable `main`, checked in that order).
- Core: Rust crate (`Cargo.toml`, `rust/src`), binaries `ul` and `unlaw`; deps limited to `toml_edit`, `sha2`, `libc`, `crossterm` (games), `serde_json` (`ul lm` API). Dispatcher, config, system commands, completion, doctor, shell integration and project templates live there. Current release is 3.1.0 (`ul --version` adds the build commit); `Cargo.toml` and `src/unlawful/__init__.py` versions must match (build.rs enforces it).
- Commands: Python 3.11+, standard library only. `src/unlawful` holds seeded command sources, their help (`command_help.py`), legacy hashes and `DEFAULT_CONFIG`; `rust/build.rs` runs `rust/gen_assets.py` to embed them, so build needs Python 3.11+. System command help lives in `rust/src/help.rs`.
- Command contract: commands receive `UNLAW_COMMAND`, `UNLAW_COMMAND_DIR`, `UNLAW_CONFIG_DIR`, `UNLAW_STORAGE`; `main.py` runs with `UNLAW_PYTHON`, else `core.python`, else the newest `python3.x` on PATH. Descriptions for `ul commands --describe`/completion come from `help.txt`, the `main.py` docstring or a script's first comment, never by running the command. Changing a seed's content requires adding the previous release's hashes to `LEGACY_SOURCE_HASHES`.
- User data: `${XDG_CONFIG_HOME:-~/.config}/unlaw`; a source build and first CLI invocation bootstrap it without overwriting user files.
- Extension rule: only system commands live in the dispatcher; every other command is seeded as standalone source into `${XDG_CONFIG_HOME:-~/.config}/unlaw/commands/<name>/main.py`. Legacy official import wrappers are migrated, but manually edited command files are never overwritten.
- Seeded sources contain only that command's logic and minimal config helpers/defaults; unrelated command code must never be concatenated into them.
- Configuration: `config.toml` is validated and atomically written with `toml_edit`, preserving comments and unknown keys; validation rules exist in both `rust/src/config.rs` and `src/unlawful/config.py` and must stay identical; aliases are token arrays, not shell strings.
- Test: `cargo test`, `cargo clippy --all-targets`, and `python -m unittest discover -s tests -v` (black-box tests build and run `target/debug/ul`; tests must never reach the network or real user tools — use fake executables on a restricted PATH and local servers).
- Build check: `cargo build --release`; install with `cargo install --path . --root ~/.local --force` (install.sh does this from GitHub).
- Project templates live in `templates/{commands,python,rust,cpp}` and may override generated files.
- macOS Harness is optional; only `ul mac` and its doctor checks may depend on it.
- Personal commands: `todo` edits the configured Obsidian `TODO.md`; `capture` uses macOS `screencapture` and optional ffmpeg; `music`, `work`, and `yt` drive macOS apps/URLs.
- Telegram credentials: bot token is stored in macOS Keychain under service `unlaw.telegram`; only the chat id is in `config.toml`.
- Local AI: `ul lm` is a Rust builtin (`rust/src/builtin/lm/`) with its own MLX engines; LM Studio and Ollama are not used. Rust owns CLI, HTTP server (127.0.0.1 only, Host-checked, CORS only with `--cors`; OpenAI `/v1/*` incl. images/speech/videos + Ollama `/api/*`), model store (HF cache; converted models in `storage.root/models`) and supervisors: one worker process per lane (`core:chat`, `core:helper`, `core:video`, `image:image`, `bonsai-image:image`) with cross-lane memory accounting. MLX runs in `worker.py` (JSON lines over stdin/stdout) inside venvs built on uv-managed Python 3.13 from pinned `requirements*.txt` (core; mflux image; PrismML mflux fork for Bonsai Image); changing pins rebuilds that engine. API jobs never read local paths (`local` is set only for terminal jobs). A worker crash or OOM must never stop the server; there is never a cloud fallback. Tests use `UNLAW_LM_PYTHON` + `UNLAW_LM_WORKER` with a fake worker and `HF_HUB_CACHE`.
- Terminal arcade: `ul game` is built into the Rust core (`rust/src/builtin/game/`, crossterm): Tetris, Snake, Minesweeper and Space Invaders with mouse support, close to the originals; games are state machines tested headlessly through the `Screen` trait. Best scores live in `storage.root/runtime/arcade.toml`.
- Storage: captures, Telegram downloads, and runtime files default to the single configurable `storage.root` (`data`, relative to the Unlaw config directory).
- Arcade difficulty: every game supports `easy`, `normal`, and `hard` (hard must stay genuinely hard); the default comes from `games.difficulty`.
- Built-in Rust commands (`zip`, `game`, `lm`) resolve after `commands/<name>/`, so user folders override them; untouched old Python seeds (known hashes, or known hashes ignoring blank lines) are removed on startup.
- Rust user commands: `ul create command <name> --lang rust` writes a Cargo project; the runner rebuilds it when sources are newer than `target/release/<bin>`.

- Every new or changed command must support `--help` and `-h` before any side effects, returning 0 and showing its purpose, all actions/options, defaults, dependencies and examples. Keep help accurate when behavior changes; include it in standalone seeded sources and command templates.
- YouTube downloads: `ul yt download <URL> [--format mov|mp4|raw] [--audio] [--quality <height>] [--output <directory>]` invokes optional external yt-dlp and ffmpeg/ffprobe, defaults to MOV in `storage.root/youtube` (`raw` keeps source codecs/container; `--audio` saves MP3), and never downloads an entire playlist or overwrites existing files.

- YouTube subtitles: `--sub` or `--sub-lang [code]` saves only Markdown (original language if omitted); invalid codes list available tracks. Markdown starts with the video link and labels authored/automatic captions. `--full` saves video, separate MP3 and Markdown using one media download; unavailable/failed captions report an incomplete result while retaining saved media. Subtitle-only mode needs no ffmpeg.
- Archives: `ul zip` (Rust, `rust/src/builtin/zip.rs`) creates zip (default `zip.format`), 7z, rar (needs `rar`), tar.zst/xz/gz and auto-extracts by content; levels use one 0-9 scale (7-Zip names, default `max` = 7) mapped to each format's native settings, and media-heavy input without an explicit level drops to 1; 7-Zip is preferred with zip/bsdtar fallbacks. It never overwrites (adds " 2"), strips macOS junk unless `--keep-junk`, extracts multi-item archives into a folder, and feeds passwords via stdin, never argv.
